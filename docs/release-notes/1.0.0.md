Headroom's first public release shows your remaining AI subscription quotas in one overview and in widgets.

## What is in it

- Headroom supports Claude, ChatGPT Codex, GitHub Copilot, Grok, Z.AI, Kimi Code, OpenCode Go and JetBrains AI.
  You can add several accounts per provider.
- The overview shows weekly or monthly usage, session usage and the difference from an even usage rate.
  Sort accounts or drag them into your preferred order.
- Weekly reset alerts appear as heads-up notifications after Headroom confirms the reset with the provider.
- Resets and Stats show upcoming resets, alert switches, each window's history and quota usage statistics.
- Rings, Bars, Shape and Countdown widgets show usage on the home screen and lock screen.
- Settings controls used or remaining values, light or dark theme, wallpaper colours or eight palettes, reduced motion and background update frequency.
- Optional effects include a sparkling shimmer after usage updates and confetti after a reset while the app is open.
- The experimental reset island expands from the camera cutout after a reset while Headroom runs in the background.

## Installing

Download `headroom-1.0.0.apk` from this release and open it on your phone.
Headroom requires Android 16 or later. Use `headroom-1.0.0.apk.sha256` to check the download.

Uninstall earlier self-built versions before installing this release.
Their different signing key prevents Android from installing this release as an update.

Headroom reads usage from undocumented endpoints. Providers can change those endpoints at any time.
Headroom has no affiliation with these providers.
